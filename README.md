
# 🛒 QuickKart – Grocery Shopping Website

QuickKart is a responsive grocery shopping website inspired by
quick-commerce applications.

## Features
- Product search and category filters
- Shopping cart with quantity controls
- Automatic subtotal and delivery fee calculation
- Responsive mobile-friendly design
- Interactive checkout demo

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open index.html in your browser.
3. Search products and add them to your cart.

## Disclaimer
This is an educational project. It does not process real payments
or place actual orders.
