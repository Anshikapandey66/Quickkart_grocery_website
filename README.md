
# 🛒 QuickKart 2.0

A responsive grocery shopping website inspired by quick-commerce applications.

## Features
- Product search
- Category filters
- Price sorting
- Product images and ratings
- Add to cart and quantity controls
- Wishlist
- Persistent cart using localStorage
- FRESH10 coupon code
- Automatic bill calculation
- Checkout and order confirmation demo
- Responsive design

## Technologies
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Keep all files in the same folder.
3. Open index.html in your browser.

## Coupon
Use `FRESH10` on eligible orders of ₹299 or more for 10% off.

## Disclaimer
This is a frontend learning project. It does not process real payments or deliver products.
